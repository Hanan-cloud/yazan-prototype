Cozy Feedback SFX - Free  (AmazingSFX)
=====================================

48 sound effects for game UI, items, crafting and rewards:
16 events x 3 variations each, so repeated actions don't sound identical.

Folders
  UI        Hover, Select, Confirm, Cancel, Error, Notification
  Items     Pickup, Store, Coin
  Crafting  Start, Success, Fail
  Rewards   Common, Rare, Level Up, Quest Complete

Format: WAV, 48 kHz, 24-bit, mono. Peak -1 dBFS, trimmed (no silence at start/end).

How to use: drag any clip onto an AudioSource, or call
  audioSource.PlayOneShot(clip);
For variety, pick one of the numbered variations at random each time.

How these were made: every sound is synthesized from original code
(sine partials, filtered noise, a small synthetic reverb). No recordings,
samples, presets or AI audio models were used. The synthesis code was
written with the help of an AI coding assistant.
